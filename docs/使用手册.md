# RVC 实时变声 · 使用手册

面向使用者的说明书。**所有踩过的坑都记在第五节**，遇到问题先翻那里。

---

## 一、它是什么

```
原版 realtime_gui.py   = 引擎（音频、推理、模型，一行没改）
control_server.py      = 遥控接口（住在引擎进程里，一个守护线程）
panel.html             = 遥控面板（浏览器打开，电脑/手机都能用）
```

一句话：**原版的引擎 + 网页的遥控器**。所以音质和跟随速度与旧界面完全一致，只是把操作台搬到了浏览器。

---

## 二、电脑上怎么用

1. 双击 **`启动.bat`**
   - 弹出一个黑色命令行窗口（**别关它**，关了就退出了）
   - 同时弹出**原版的 Tk 窗口**——那是引擎本体，可以最小化，不用管它
   - 浏览器会自动打开面板
2. 面板里：`01 音频设备` 选好输入/输出 → `02/03` 调参数 → 点「**应用并开始**」
3. 停：点「停止」
4. 只想再打开面板（不重启引擎）：双击 `打开面板.bat`

---

## 三、手机上怎么用（局域网遥控）

**前置条件**：手机和电脑连**同一个 Wi-Fi**（电脑接网线也行，只要在同一路由器/同一网段）。手机**不要开 VPN**。

1. 电脑上双击 `启动.bat`
2. 看黑色窗口里这几行（**每次只挑 `192.168` 开头那条**）：

```
[遥控] 本机   http://127.0.0.1:8898?k=xxxxxxxx        ← 只有电脑自己能开
[遥控] 局域网 http://192.168.101.2:8898?k=xxxxxxxx    ← 手机用这条
[遥控] 局域网 http://172.25.128.1:8898?k=xxxxxxxx     ← Hyper-V 虚拟网卡，忽略
[遥控] 局域网 http://26.245.108.171:8898?k=xxxxxxxx   ← VPN 网卡，忽略
```

3. 手机浏览器里输入上一步那条 **`192.168` 开头的完整地址**，**`?k=xxxxxxxx` 这段也要一起复制**
4. **第一次多半打不开**：回到电脑，会看到 Windows 防火墙弹窗 → 勾「**专用网络**」→ 允许访问
   （如果没弹窗：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到 `python.exe`，勾上「专用」）
5. 打开成功后，建议用浏览器菜单「**添加到主屏幕**」，以后像 App 一样点开
6. 令牌会记在手机浏览器里，之后不用再输；换了手机或清了缓存，面板会弹框让你输入 `?k=` 后面那串

> **令牌（`?k=xxxxxxxx`）就是钥匙**：别截图发群里。想换钥匙：删掉 `control_token.txt`，重启一次即可。

## 四、模型与预设

### 模型（`03 模型`）

- **切换**：在「已存模型」里选中就直接开始加载（**选中即切换**，约 30 秒）。不选就是「不切换，用当前」。
- 登记、导入、删除收在下面「管理模型」抽屉里，点开才展开：
  1. **登记**：填「别名」+ `.pth 路径` + `.index 路径` → 「存为别名」。相对项目根的路径（如 `assets/weights/example.pth`）和绝对路径都行。
  2. **导入文件**：点「上传文件」选 `.pth` 或 `.index`，会按扩展名自动归位到 `assets/weights/` 或 `assets/indices/`，并回填路径。
  3. **删除**：只删登记，**不删文件**。

### 预设（`01 预设`）——一键换场景

预设把**设备 + 模型 + 参数**打包成一套，因为这三者总是一起变的（比如“直播用”和“练歌”各一套）。

- **切换**：选中即生效，一次把设备、模型、参数全下发（换模型时同样约 30 秒）。
- **保存**：调好面板后点开「管理预设」，填个名字 → 「保存当前为预设」。
- **删除**：选中预设后点「删除」（不影响模型文件）。

两份登记表都存在引擎那侧（`models.json` / `presets.json`），**电脑和手机共用同一份**。

### 关于模型授权（请认真看）

- 本工具**不附带任何音色模型**；示例路径统一用中性名（`example.pth`），不指向任何具体音色。
- 网上流传的 RVC 音色模型**绝大多数授权不明**；真人音色（名人、主播等）还涉及**人格权 / 声音权**。自己用可以，**别对外分发**。
- 想找**完全开源**的练手素材：用公开数据集自己训练最干净——
  - **VCTK**（CC BY 4.0，多说话人英文语料）
  - **LJSpeech**（公有领域，单人英文语料）
- RVC 官方仓库自带的底模（`assets/pretrained_v2/*`）属于 RVC 项目（MIT），但它是**训练用底模，不是音色模型**，不能直接拿来变声。

> 注：原版引擎要求**索引文件必填**，`.index 路径` 不能留空（没索引的模型请先做一个 `added_xxx.index`）。

## 五、参数速查

| 参数 | 作用 | 调大的后果 | 调小的后果 | 常用值 |
| --- | --- | --- | --- | --- |
| 采样长度 | 每次处理的音频块时长 | 延迟变大、算力变省 | 延迟变小、算力暴涨 | 0.06 最跟手但最吃 CPU；0.15 是省算力甜点 |
| 额外推理时长 | 每块重算的上下文长度 | 连贯性好、算力线性上涨 | 省算力、偶尔接不上 | 1.0 左右；2.0 很吃 CPU |
| 音调 | 半音 | 声音更高 | 声音更低 | 男变女约 +8 ~ +12 |
| 性别因子 | 共振峰偏移，调声线粗细 | 更薄/更亮 | 更厚/更闷 | -1.75 左右 |
| 检索特征占比 | 用检索特征去贴目标音色 | 更像，但可能有杂音 | 更稳，但没那么像 | 0.3 左右 |
| 响度因子 | 输出响度贴合原声的程度 | 更贴原声 | 更贴模型 | 0.7 |
| 响应阈值 | 静音门限，**-60 表示关闭** | 更早静音（省一点点算力） | 更敏感 | -60 = 关；-40 左右可挡底噪 |
| f0 算法 | 音高提取算法 | — | — | `rmvpe` 最好也最贵；`pm` 最快；`fcpe` 居中 |

**一条必须知道的算力账**：每秒钟真正要算的音频量 = `(额外推理时长 + 采样长度) ÷ 采样长度` 倍。

- `0.06 + 2.0` → 约 **34 倍**（跟手最好，CPU 最忙）
- `0.15 + 1.0` → 约 **7.7 倍**（省很多，延迟约 0.15 秒）

这就是为什么「0.06 秒」这套配置会让 CPU 明显忙起来——不是故障，是价钱。

## 六、常见问题（都是我们真踩过的）

### Q1 任务管理器里 CPU 满载

排查顺序：
1. **先看是不是残留进程**：任务管理器 →「详细信息」→ 找 `python.exe`，右键看命令行。
   跑着我们工具的残留（命令里带 `web_ui.py` / `_serve_panel` / `_test_`）就是元凶。
2. 或者直接双击 **`清理残留.bat`**：它会清掉我们工具的残留进程，并列出正在运行的原版进程和 CPU 前几名。
3. 如果只有原版在跑，那 **3~4 个核是 `0.06 秒 + 2.0 秒` 这套参数的正常代价** → 把「采样长度」调大或「额外推理时长」调小。
4. 其他常驻吃 CPU 的：数位板驱动（`parbloDriver` 空转能占 1 核）、音乐软件、同步盘等。

### Q2 声音一卡一卡（断音 / 毛刺）

按顺序排除：
1. **CPU 被抢**（见 Q1）——实时变声最怕抢不到 CPU，这一条占大多数。
2. **设备类型**：「MME」是 Windows 的模拟层，抖动偏大；换成 **WASAPI** 下的同名设备通常更稳。
3. **参数太激进**：`采样长度 0.06` 本身就是极限配置，改 `0.15` 会稳很多。
4. 还卡：换 USB 口 / 换声卡；关掉其他软件的「独占模式」。

### Q3 面板里下拉菜单的选项"看不见"

已修复。原因：下拉列表是**原生控件**，不去管它就用系统默认底色；深色模式下我们的字是近白色，撞在白色弹窗上就隐身了。
修法：显式给选项上底色 + 让浏览器随深/浅色切 `color-scheme`。**若又出现，清一次浏览器缓存。**

### Q4 黑窗口里中文乱码（锟斤拷 / 方块）

- 已修：`.bat` 全部用**纯 ASCII** 写（cmd 是按本地 ANSI 读 .bat 的），中文一律交给 Python 打印；脚本里设了 `PYTHONUTF8=1`。
- 如果你看到的是**方块 □□□**，那是**控制台字体**问题：右键窗口标题栏 → 属性 → 字体 → 改成「新宋体」。

### Q5 手机打不开面板

- 手机和电脑是不是**同一个 Wi-Fi**（访客网络不行）
- 电脑**防火墙放行了没**（见第三节第 4 步）
- 地址是不是抄成了 `172.25.*` / `26.*` 那两条虚拟/VPN 网卡 —— 要用 **`192.168`** 那条
- 手机开 VPN 了 → 关掉

### Q6 面板显示"未连接"

- 引擎没在跑（那个黑窗口关掉了？）
- 打开的地址不是带 `?k=` 的那条，或令牌过期（换钥匙后旧链接会失效）

### Q7 想换模型

- 模型放 `assets/weights/*.pth`，索引放 `assets/indices/*.index`
- `configs/config.json` 里的 `pth_path` / `index_path` 指向它们
- rmvpe 的音高模型在 `assets/rmvpe/rmvpe.pt`

## 七、文件地图

| 文件 | 说明 |
| --- | --- |
| `启动.bat` | 一键启动（拉起原版引擎 + 遥控接口，并打开面板） |
| `打开面板.bat` | 只打开面板 |
| `清理残留.bat` | 清掉我们工具的残留进程 + 显示 CPU 前几名 |
| `realtime_gui.py` | **原版引擎**（只在两处加了小钩子：启动遥控接口、监听遥控事件） |
| `control_server.py` | 遥控接口（状态、参数下发、令牌校验） |
| `panel.html` | 遥控面板——**改样式只动这一个文件** |
| `configs/config.json` | 参数契约（面板下发后写在这里） |
| `models.json` | 模型库登记表（别名 → 路径），自动生成 |
| `presets.json` | 预设包（设备 + 模型 + 参数），自动生成 |
| `control_token.txt` | 访问令牌（首次自动生成，别外传、别提交） |
| `patches/realtime_gui.control.patch` | 对原版文件做的改动补丁（便于对着全新检出重放） |

## 八、已知限制

- 面板是"遥控器"，不是替代原版窗口——引擎仍然需要那个进程活着。
- 令牌以明文出现在地址栏（局域网内够用；要更强需要另换方案）。
- 参数范围是预设的（如「额外推理时长」0~3 秒）。
- `web_ui.py`（ONNX 轻量档，给没有 N 卡的机器用）目前有 CPU 异常，暂不作为高档启动目标。
